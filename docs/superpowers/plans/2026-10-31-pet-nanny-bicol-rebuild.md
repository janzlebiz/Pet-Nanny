# Pet Nanny Bicol Minimalist Website, Mobile App & Owner Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimalist redesigned Pet Nanny Bicol customer website, owner dashboard, and standalone Android/iOS mobile app sharing a tested TypeScript domain core.

**Architecture:** A TypeScript project containing a shared, unit-tested domain core (`src/core/`), a minimalist Vite + React web application housing both the Customer Website, Owner Dashboard, and Interactive Mobile App Simulator (`src/`), and a standalone React Native / Expo mobile application (`mobile/`) with `app.json` and `eas.json` configured for Android `.apk`/`.aab` and iOS `.ipa` store builds.

**Tech Stack:** TypeScript, React 19, Vite, Vitest, Lucide React (vector SVG icons), React Native / Expo SDK 52 (`mobile/`), CSS Custom Properties generated by `ui-ux-pro-max`.

**Spec:** `docs/superpowers/specs/2026-10-31-pet-nanny-bicol-redesign-design.md`

## Global Constraints

- Design tokens must follow `design-system/pet-nanny-bicol/MASTER.md` (`#FFF7ED` background, `#FFFFFF` cards, `#F97316` primary, `#2563EB` accent, `Varela Round` + `Nunito Sans`).
- Never use emojis as structural UI icons; use vector SVG icons (`lucide-react` / `@expo/vector-icons` / inline SVG).
- All prices must format with the Philippine Peso symbol `₱` (never `?`).
- Touch targets on mobile views must be at least `44px` (`48dp` Android) high with `>= 8px` spacing.
- WhatsApp integration must target `+63 956 902 5256` (`639569025256`).

## Review Focus

- Philippine phone numbers in both `09XXXXXXXXX` and `+639XXXXXXXXX` formats must validate cleanly, while invalid strings fail with clear field messages.
- Closed dates blocked by the owner on the calendar must reject customer booking requests on that date.
- First-time booking 10% discount must accurately compute across both single-price services (`₱350` -> `₱315`) and range-price services (`₱1,200–1,800` -> `₱1,080–1,620`).
- Owner Dashboard financial metrics must separate Completed Revenue from Confirmed Pipeline Value.
- Mobile booking wizard must validate each step before advancing so users never hit hidden errors on offscreen steps.
